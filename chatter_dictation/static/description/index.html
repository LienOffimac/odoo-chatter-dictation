Chatter Dictation

Speak your notes instead of typing them

This module adds a microphone button to the chatter composer. Click the button, speak, and your words appear as text in Log note or Send message.

How it works

  • Click the microphone next to the emoji icon in the chatter.
  • The icon turns red and blinks while you are dictating.
  • What you say is appended to the existing text. You can edit the text afterwards as usual.
  • Click the button again to stop.

Good to know

  • Browser support: works in Chrome, Edge and Safari. Firefox does not support browser speech recognition, so the button has no effect there.
  • Privacy and data sent to third parties: speech recognition is done by your browser's speech service. In Chrome and Edge, the audio is sent to the servers of Google or Microsoft for this purpose. Odoo only receives and stores the resulting text. Users are asked for confirmation the first time they use the button, and the browser asks for microphone access.
  • Requirements: a secure (HTTPS) connection is needed for microphone access.
  • No setup: installing the module is enough. It does not add any data to the database and needs no activation key.
